# Piyas Das — Portfolio Website

Personal portfolio website for **Piyas Das** (SAP ABAP Developer | IS-U & CRM Workflow Specialist).

## 🚀 Free Hosting & Publishing Options

This website is a lightweight, zero-dependency, ultra-fast static site HTML/CSS/JavaScript. All emergent dependencies and backend proxy links have been removed so you can publish it 100% free on any platform.

### Option 1: Vercel (Recommended - 1 Min Setup)
1. Install Vercel CLI: `npm i -g vercel` or push this project folder to GitHub / GitLab.
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import this folder/repository.
4. Framework Preset: **Other** or **Static HTML**.
5. Click **Deploy**. Your site will be live instantly with free SSL!

### Option 2: Netlify (Drag & Drop Deployment)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`c:\Users\w 10\Desktop\New folder (2)`).
3. Netlify will publish your site in seconds with a free `.netlify.app` URL and free HTTPS.

### Option 3: GitHub Pages (Free Permanent Hosting)
1. Create a repository on GitHub (e.g., `piyasdas-portfolio`).
2. Push all files in this directory to `main` branch.
3. Go to Repository **Settings** -> **Pages**.
4. Set Source to `Branch: main` / `root (/)`.
5. Click **Save**. Your site will be published at `https://<your-username>.github.io/piyasdas-portfolio`.
